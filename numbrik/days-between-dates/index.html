Days Between Dates

Count the days, weeks and weekdays between two dates, or count down to a holiday, deadline or trip.

Loading calculator…

How to use the Days Between Dates

  1. Pick a start date and an end date.
  2. Read the number of days, weekdays, weeks and approximate months.

How it works

The start date is not counted and the end date is, so Monday to Friday of the same week is 4 days. If you want to include both dates, add 1.

Weekdays are Monday to Friday. Public holidays are not removed, because they differ by country, state and employer; subtract them yourself for an exact working-day count.

Formula

Days = end date − start date
Weeks = days ÷ 7

Example

From October 20, 2026 to Christmas Day is 66 days, which includes 48 weekdays and is about 9.4 weeks.

Common uses

  • Countdowns. Days until Christmas, a wedding, a holiday or a product launch.
  • Deadlines and notice periods. Check how many days are left on a 30-, 60- or 90-day notice, return window or free trial.
  • Pregnancy and baby milestones. Count days or weeks since a date. For medical dates, follow your doctor's schedule.
  • Travel and visas. Count the days of a trip, or how long you have stayed somewhere. Visa rules may count arrival and departure days differently, so check the official rule.
  • Project planning. Use the weekday count to estimate working days, then remove public holidays for your state or province.

Counting tips

Some contracts say "within 30 days" and count from the day after an event, which matches this calculator. Others include the first day. When a date really matters, such as a legal deadline, read the wording carefully and confirm with the organisation that set it.

Frequently asked questions

How many days until Christmas?

The calculator opens with today's date and December 25 filled in, so the answer is on screen as soon as the page loads.

Does it include the end date?

Yes, the end date is counted and the start date is not. Add 1 to include both.

How many weeks is 90 days?

12 weeks and 6 days, or about 12.9 weeks.

Does it skip public holidays?

No. It counts Monday to Friday. Subtract the public holidays that apply to you.
